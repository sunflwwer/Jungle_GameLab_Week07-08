# [WEEK07] 콘텐츠 확장 및 로그 분석

크래프톤 정글 게임랩 7주차에 진행한 **콘텐츠 확장 및 로그 분석 그룹 과제**입니다.

## 🎯 프로젝트 소개

기존 게임 빌드를 5~10분 동안 몰입해 플레이할 수 있도록 확장하고, 플레이 로그를 수집·분석하여 의도한 게임 경험이 유도되는지 검증했습니다.

## 👩🏻‍💻 담당 역할

2D 스프라이트 이미지 편집과 프로그래밍을 담당했으며, 게임의 핵심 기믹을 구성하는 기능과 동작 로직을 구현했습니다.
